# Сервис вишлистов КупиПодариДай

## Описание проекта:
Этот сервис представляет собой Backend-приложение для создания и управления вишлистами, которое позволяет пользователям делиться своими желаниями и вносить деньги на подарки для других. Каждый зарегистрированный пользователь может указать, какой подарок он хочет получить, а также пожертвовать деньги на подарок другому пользователю, указав сумму, которую готов потратить.

Проект реализован с использованием NestJS и TypeScript, а данные хранятся в реляционной базе данных PostgreSQL. Сервис включает в себя функциональность для регистрации пользователей, создания и управления вишлистами, а также возможность обмена подарками между пользователями.

## Инструменты и технологии:
* **TypeScript** — современный язык программирования, обеспечивающий строгую типизацию для JavaScript.
* **NestJS** — фреймворк для создания эффективных и масштабируемых серверных приложений на TypeScript.
* **TypeORM** — библиотека для работы с реляционными базами данных в TypeScript.
* **PostgreSQL** — мощная и надежная реляционная база данных, использованная для хранения данных.
* **Swagger** — инструмент для документирования и тестирования API.
